## How to choose a creator

1. **Start with the buyer, not the reach.** A sales tool belongs on a show sales leaders hear every week; a developer tool belongs where engineers watch builds on screen.
2. **Use median views on the last six videos**, not subscribers. Subscribers measure history; recent medians measure today.
3. **Ask for audience data:** country, job level, company size.
4. **Match the format to the product.** Tutorials suit tools people must see working; interviews suit products with a story; newsletters suit launches and offers.
5. **Measure with a code or tracked link**, and judge the result against confirmed pipeline, not platform clicks alone.
